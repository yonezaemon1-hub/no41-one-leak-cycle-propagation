## 1. 引用する既知結果

### K1：パスの両端は1点leakに耐える

Alameda–Kritschgau–Warnberg–Young, *On leaky forcing and resilience*,
arXiv:2008.06552v1, **Theorem 4.4**（PDFの13頁、本文頁13）は、
木について次数が漏れ数以下の頂点集合が最適なleaky forcing集合である
ことを示す。漏れ数1のパスに適用すると、両端が1-leaky forcing集合になる。
同論文の定義は、頂点がforceできなくなるが青くはなれるモデルである。[1]

このパスの結果は、Alameda–Dillman–Kenter (2024), **Proposition 3.1**
（AJC誌面312頁）にも直接記載され、同論文の**Theorem 3.3**は上の木の
定理を引用している。[2]

### K2：毎段少なくとも1点進めば、時間は初期白数以下

Hogben–Huynh–Kingsley–Meyer–Walker–Young,
*Propagation time for zero forcing on a graph*, arXiv:1410.4191v1,
**Remark 1.8**（PDFの3頁）は、各段に少なくとも1回forceすることを理由に、
通常のzero forcingの最大伝播時間を頂点数と最小配置数で上から抑える。[3]

ここで使うのはその計数理由である。固定した禁止頂点と初期集合について、
同期過程が完了するなら、完了前に色が変わらない段はない。もし変わらなければ、
色も禁止頂点も同じままなので以後も進まないからである。従って初期白数Wに
対して完了時間はW以下。この固定leakへの適用は、ここで明示的に確認した補足で、
原文のRemarkをそのままleak付き定理として引用するものではない。

### K3：容量と整数最適化の基礎

Butler–Young, *Throttling zero forcing propagation speed on graphs*,
AJC 57 (2013), §2, pp.66–68 は、通常のforcing chainの容量制約とパスの配置、
重み付きの最適化の枠組みを扱う。[4]

No.41の根号式がこの文献にそのまま掲載されているとは主張しない。下の
最適化はK1から得る時間式に対する初等的な計算であり、独立の新原理に数えない。

## 2. モデルと目標

n>=3の単純無向サイクルC_nと初期青集合Bを固定する。その後で相手が
固定1頂点xを選ぶ。xはforceできないが青くなれる。各段の開始時の色で
全ての可能なforceを決め、同時に適用する。時刻0は初期色。

p_G(B;x)を完了時間、停止なら無限大とし、

    T_G(B) = max_x p_G(B;x)

とする。Bが全点ならT=0。Bが真部分集合で隣接青がなければ、青はどれも
白い隣を2点持ち、最初から停止する。以下はBが真部分集合で隣接青を持つ場合。

目標の定理Aは、長さ2以上の初期青runの間の弧I_iについて、初期白数をW_iと
したとき、

    T_(C_n)(B) = max_i W_i                                      (A)

である。定理Aを途中の仮定として使わず、次の還元から導く。

## 3. 補足観察O1：初期青同士の辺は、時間を変えずに除ける

任意のグラフGについて、初期青同士を結ぶ辺の集合Fを選び、H=G-Fとする。
頂点集合と初期集合、禁止頂点は変えない。

現在の青集合をC（Bを含む）とすると、全ての頂点vで

    N_H(v) \ C = N_G(v) \ C。

取り除いた近傍は最初から青であり、現在も青だからである。従って白い隣の
集合は変わらない。また取り除いた辺の先は常に青なので、その辺を白への
forceに使うことは一度もない。各段の可能なforceと禁止条件は同じになる。

時刻0からの帰納法により、**各段の青集合そのものが一致する**。特に、

    p_H(B;x) = p_G(B;x)    for every fixed x。                  (1)

これは任意の辺削除が安全だという主張ではない。両端が初期青であることが
条件である。頂点数、配置数、禁止頂点の候補、各段の着色時刻を全て保存する。
O1は今回ここで証明した基本的観察で、既存の番号付き時間定理として引用しない。

## 4. サイクルを独立なパスへ分解する

O1で、初期青同士を結ぶ全ての辺を取り除く：

    H = C_n - E(C_n[B])。

Bが真部分集合で隣接青があるので、Hは複数のパスと孤立頂点からなる。
白を含む各成分P_iは、ちょうど

    P_i = a_i, I_i, b_i

であり、a_iとb_iは元の長い青runの外側の端点である。両端は初期青。
内部の初期青は互いに隣接せず、全て孤立した青である。長いrunの内側の
余剰青は、既に青い孤立成分になる。

長さ2のrunでは、取り除く青青辺の両端が別のパスを担当する。長いrunが
一つのときも両端は別の頂点なので、一本のパスが得られる。端点の重複や
他成分からのforceはない。P_iに含まれる初期白の数は元のW_iと同じ。

## 5. K1とK2による上界

P_iでは両端a_i,b_iが初期青であり、K1によりこの両端だけで1点leakに耐える。
内部の初期青を追加しても、到達可能性は失われない。

この単調性も確認できる。青集合CをDに増やしたとき、Cで有効なu→vに対し、
vがDでも白ならuと他の全ての隣はDで青なので、そのforceはDでも有効。
vがDで青なら既に目標を満たす。固定した同じleakについて、各段の青集合の
包含が帰納的に保たれる。

よって、leakがP_iのどこにあっても、内部青を含む初期集合で完了する。
leakが成分外ならP_iにはleakがなく、やはり完了する。K2の計数理由により、

    p_(P_i)(B ∩ V(P_i); x) <= W_i。

全成分は並行して進み、孤立成分は初めから青なので、(1)を使えば

    p_(C_n)(B;x) <= max_i W_i    for every x。

従って

    T_(C_n)(B) <= max_i W_i。                                  (2)

ここでは内部leakが初期白か青かを場合分けする必要がない。任意の位置を許す
既知のパス定理が、その場合をまとめて扱う。

## 6. 補足観察O2：片端leakで計数上界を達成する

P_jをW_jが最大の成分とし、その端点b_jをleakにする。
P_jの初期白をa_jからb_jへ向かう順にw_1,...,w_(W_j)と並べる。

時刻t（0<=t<=W_j）に初期白のうち青くなっているものは、ちょうど
w_1,...,w_tであることを帰納法で示す。t=0では成り立つ。

t<W_jとして、その段の開始時を考える。

* w_(t+1)の直前は青で、leakではない。t=0なら端点a_j、t>=1なら
  w_t自身またはw_tとw_(t+1)の間の初期青である。その後ろ側は既に青
  （端点なら近傍なし）なので、w_(t+1)へのforceが有効。
* w_(t+1)より先の初期青singletonは、まだ白の隣を2点持ち、先へforce
  できない。w_(t+1)がこの段で青くなっても、判定は段の開始時なので、
  同じ段に飛び越えて次の白を青くすることはできない。
* 先の非初期頂点は白であり、逆側の端点b_jからのforceはleakで禁止。

従って新たに青くなる白は、毎段ちょうどw_(t+1)の1点である。帰納法により

    p_(P_j)(B ∩ V(P_j); b_j) = W_j。

成分外から入る辺はなく、(1)が全ての段を保存するので

    T_(C_n)(B) >= W_j = max_i W_i。                            (3)

(2)と(3)を合わせて(A)を得る。O2は一方向の数え上げであり、今回ここで
論証した補足。K1の到達可能性の定理が、そのまま(A)を記載していたとしない。

## 7. 最適配置数・締切・和の式も同じ導出から出る

### 固定配置数k

2<=k<nとする。長い青runの数rはfloor(k/2)以下、白数は合計n-k。
(A)から

    n-k = Σ_i W_i <= r T(B) <= floor(k/2) T(B)。

逆に、r=min(floor(k/2),n-k)個の青run（各2点以上）を作り、余剰青を一つの
runにまとめ、n-k個の白をr個の非空の隙間に均等に分ければ下界を達成する。
白数がfloor(k/2)未満なら、各隙間に白を1点置き、時間1で達成する。
従って

    tau(n,k) = ceil((n-k)/floor(k/2))。

k=nでは0、k=0,1では無限大。

### 締切t

整数t>=0の実現条件はn<=k+t*floor(k/2)。kの偶奇で解けば

    m(n,t) = min(2 ceil(n/(t+2)),
                 2 ceil((n-1)/(t+2)) + 1)。

t=0では該当する偶奇がk=nを与え、m(n,0)=n。k=0,1は不可なので、
m(n,t)=2であることとt>=n-2が同値。nを超える候補は小さい方に勝てない。

### 配置数と時間の和

整数コストc=k+t>=3での容量は、偶数k=2rでr(c+2-2r)、
奇数k=2r+1でr(c+1-2r)+1。偶数の容量から奇数の容量を引くとr-1>=0。
よって偶数配置数で十分で、

    max_(1<=r<=floor(c/2)) r(c+2-2r) = floor((c+2)^2/8)。

これは平方完成と整数への丸めで得る。n>=3に対して
c*=ceil(sqrt(8n))-2は3<=c*<=nを満たすので、最大化するrを選び、
k=2r、t=c*-2rとして先の均等配置を使えば達成する。従って

    min_B (|B|+T(B)) = ceil(sqrt(8n))-2。

これらは全て(A)の帰結である。K3にあるパスの容量最適化と同じ種類の計算で、
新しい最適化原理を導入していない。

O1とO2は短いが、省くと引用だけで(A)が証明されたことにはならない。
特に「到達可能性の同値性」だけを「時間の同値性」として使ってはいない。
一般グラフのvertex/edge/specified leakの時間同値性も、この証明には使っていない。
